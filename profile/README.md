## Ethical Consulting

**We break systems so that others can't.**

Ethical Consulting Kft. is an independent cybersecurity company based in Budapest and operating since 2014. Our work covers penetration testing, red teaming, AI/LLM security testing, security assessments and defensive consulting.

This is where we publish the open-source tools and research that come out of that work.

- 🌐 [ethicalconsulting.hu](https://ethicalconsulting.hu/)
- ✉️ [info@ethicalconsulting.hu](mailto:info@ethicalconsulting.hu)

### Responsible use

Use our tools only against systems you own or are explicitly authorized to test.

### Reporting a vulnerability

If you find a security issue in one of our projects, email info@ethicalconsulting.hu. Please do not open a public issue for it.
